## Why

Editors can change existing page copy but cannot compose explanatory content. A constrained set of reusable blocks will let them build useful pages without fragmenting the site's visual language.

## What Changes

- Add an optional ordered Content sections list to Talent Pool, National Teams and stage/team pages.
- Provide rich text, text/image (left or right), quote, numbered steps, FAQ, callout and full-width image blocks.
- Preserve the fixed heroes and operational feeds; keep Talent Pool How we work first and move its calendar to the bottom.
- Render only authored content using the existing editorial design system.

## Capabilities

### New Capabilities

- `flexible-page-content`: Editor-managed content blocks within fixed page structure.

### Modified Capabilities

None.

## Impact

Sanity page schemas, shared content types and queries, one reusable renderer, page integrations, rendering tests and editor documentation. Existing documents need no migration and no new dependencies are expected.
