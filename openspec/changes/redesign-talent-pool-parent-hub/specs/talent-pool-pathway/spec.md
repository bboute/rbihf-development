## MODIFIED Requirements

### Requirement: Talent Pool stages have distinct public purpose statements
The system SHALL give U14, U15, and U16 a clear purpose statement describing why each Talent Pool stage exists and how it contributes to future national-team preparation. U18 and U20 SHALL be presented only within National Teams.

#### Scenario: User views Talent Pool stages
- **WHEN** a user opens Talent Pool navigation or overview content
- **THEN** only U14, U15, and U16 are offered as Talent Pool stages

#### Scenario: User continues beyond U16
- **WHEN** a user looks for U18 or U20 information
- **THEN** the experience directs them to the National Teams section rather than a Talent Pool stage
