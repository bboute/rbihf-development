## Why

The Talent Pool landing page currently presents important pathway information as one long narrative. Parents need a clearer operational home where they can quickly understand upcoming commitments, plan the season, find official updates, download public forms, and understand how the U14-U16 program works.

## What Changes

- Rebuild the Talent Pool landing page as a parent-first hub for U14, U15, and U16.
- Add an age-filtered calendar and year planner with confirmed and provisional event states.
- Surface Talent Pool news filtered by age group.
- Add a public document library for blank school, medical, travel, consent, and program documents.
- Condense the existing pathway narrative into a focused "How we work" section.
- Remove U18 and U20 from Talent Pool navigation and route them exclusively through National Teams.

## Capabilities

### New Capabilities
- `talent-pool-parent-hub`: Provide planning, updates, public documents, and program guidance for Talent Pool families.

### Modified Capabilities
- `talent-pool-pathway`: Limit public Talent Pool stages to U14-U16 and hand off later stages to National Teams.

## Impact

- Affected web surfaces include the Talent Pool landing page and age-category navigation.
- Sanity event documents gain planning status and optional end dates.
- A new Sanity document type stores public downloadable Talent Pool documents.
- Existing U14-U16 event and news category references remain reusable.
